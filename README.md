# Stockup

Stockup 是一个轻量的个人股票交易记录与分析面板，使用原生 HTML、CSS 和 JavaScript，无需安装应用依赖。

## 使用

Mac 用户可以双击 `启动Stockup.command` 启动服务并自动打开浏览器。第一次使用时，如 macOS 阻止打开，可在 Finder 中右键该文件，选择“打开”，再确认打开。

关闭弹出的终端窗口或按 `Control+C` 会停止本地服务。

也可以在此目录运行：

```sh
python3 server.py
```

然后访问 `http://127.0.0.1:8765`。现价和新闻功能需要通过这个本地服务打开；直接打开 `index.html` 时会提示无法连接本地 API。`file://` 和 `http://127.0.0.1:8765` 是不同的浏览器存储空间，切换前请先导出备份，再在新地址导入。

## 功能

- 记录买入和卖出，并自动汇总持有数量、剩余成本、平均成本、已实现/未实现盈亏和交易历史；支持逐笔编辑或删除。
- 在持仓行点击“卖出”，或在交易表单切换交易类型；填写卖出数量、价格和日期即可记账。
- 点击“获取现价”后按股票代码查询报价，并查看市值和未实现盈亏；也可手动维护价格。
- 查看持仓分布与累计买入成本走势。
- 点击“汇总持仓最新消息”后，按持仓搜索 Google News RSS，并展示分类后的标题与摘要片段。
- 所有交易记录保存在当前浏览器的 `localStorage`；清除浏览器站点数据会删除记录。
- 可以下载 JSON 备份文件，并从备份文件恢复；有交易记录且超过两周未备份时，页面会提醒你。
- 股票名称和备注支持中文输入；拼音输入法按回车选字时不会提交表单。

首次打开没有示例交易记录。旧版本留下的示例记录会在加载时自动清除。持仓列表的删除按钮会删除该股票的全部交易记录；“最近交易”中的编辑、删除按钮按单笔交易操作。卖出数量不能超过该笔交易日期前的剩余持仓。

## 数据说明

- 买入价来自你的记录。报价通过 Yahoo Finance 的图表接口获取，页面会标明获取时间；不同交易所报价可能有延迟，接口可用性及覆盖范围由数据源决定。输入代码时请带市场后缀，例如港股 `0700.HK`、上交所 `600519.SS`、深交所 `000001.SZ`。
- 已实现和未实现盈亏按移动平均成本计算；当前不计手续费、税费、股息或公司行动，适合个人记录参考，不应视为报税结果。
- 不同币种的总览金额按代码中的固定近似汇率折算为 USD，用于个人参考，不是实时汇率。
- 新闻需要网络连接；摘要是基于新闻标题与来源摘要的整理，不调用 AI 模型，通过本地服务请求 Google News RSS。
- 该工具用于记录和信息整理，不提供投资建议。
